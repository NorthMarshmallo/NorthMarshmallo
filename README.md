## ✨ Selected projects

### 🧭 [Fresh Knowledge Layer](https://github.com/NorthMarshmallo/AI_Agent_events/tree/v0.4.0)

**LLM agents · MCP · RAG · Evaluation**

An MCP service that gives LLM agents access to information published
after their knowledge cutoff.

- Evaluated **15 configurations** on a golden set of **164 questions**
  with reference citations.
- Reached **recall@5 of 0.97** with hybrid search and RRF.
- Compared agent architectures, including ReAct, LangGraph, answer
  critique, voting and planning.
- Added tool-call validation, an allowlist, context compression,
  cost limits and logging.

### 🧬 [AMR Prediction Service](https://github.com/NorthMarshmallo/ML_service_demo/tree/v0.4.0)

**MLOps · Kubernetes · MLflow · Airflow**

A production-like ML service that predicts one of seven antimicrobial
resistance classes from a protein sequence.

- Achieved **macro-F1 of 0.95** on a held-out test set.
- Built a continuous training workflow with data versioning and
  validation, model registration and champion–challenger comparison.
- Deployed the API to Kubernetes with CI/CD, monitoring and autoscaling.
- In a load test, handled **60 RPS at 12 ms p95** without errors.
